# MetaCoding

**We build systems from the model outward.**

Your data outlives every application written against it, so we start with the model and treat the rest as views over it. That one idea gives you data-centric backends on RDF and graph databases, a graph-native way to design software, and a control plane that keeps autonomous agents honest. The consulting is at [metacoding.io](https://metacoding.io); the projects below are the same method run in public.

## Projects

| | What it is | Where |
